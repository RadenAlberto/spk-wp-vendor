# VendorSelect — Dashboard SPK Pemilihan Vendor IT

Aplikasi satu halaman (single dashboard) untuk memilih Vendor IT proyek E-Business menggunakan metode Weighted Product (WP).

## Fitur
- Dashboard single-page
- CRUD sederhana data vendor melalui tabel editable
- Input/edit kriteria, bobot, dan jenis Benefit/Cost
- Matriks penilaian vendor 1–100
- Perhitungan bobot normalisasi
- Bobot WP
- Vektor S
- Vektor V
- Ranking otomatis
- Rekomendasi vendor terbaik
- Grafik ranking
- Export hasil ke Excel
- Tombol reset data

## Menjalankan
```bash
pip install -r requirements.txt
streamlit run app.py
```
